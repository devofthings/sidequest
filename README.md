# Sidequest

An iOS app combining short news stories and bite-sized mini-games in one swipeable feed.

## MVP

Build a private iPhone prototype to test whether alternating between reading and playing feels enjoyable.

- Short news cards with source attribution and links to the original stories.
- A small set of quick puzzles, such as mini Sudoku, chess challenges, and memory games.
- A vertical feed that makes it easy to move between stories and games.

Sidequest is the working project name. The repository currently contains project setup only; app development has not started.
