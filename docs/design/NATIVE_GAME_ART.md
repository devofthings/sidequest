# Original native game artwork

Selected for [#171](https://github.com/devofthings/sidequest/issues/171) under the owner's autonomous MVP design authorization in #13. The lead selected the six Memory faces and current White/Black King and Queen contours from the [original #159 vectors](figma-159/icons.svg). Other action-icon samples remain proposals. This selection changes artwork, not pair identities, chess rules, or game difficulty.

`MemorySymbolArtwork` and `ChessPieceArtwork` translate the source sheet's 64-point paths into native SwiftUI Shapes. The Memory card back translates the sheet's repeated 44-point chevrons. These are original Sidequest contours; no competitor art, external licensed assets, glyph fonts, paid generators, packages, or asset conversion tools are involved. Curves, silhouette points, Sun rays, Leaf stem, King cross, Queen crown and bases are preserved. Fills use the existing native palette rather than adding the proposal's approximate color values.

Memory retains the six exact rule symbols and their spoken names: star, heart, moon, sun, leaf and bolt. All hidden cards render the same back without passing their answer into its artwork. Decorations are hidden from accessibility while the existing tile labels carry hidden, revealed and matched state. Revealed faces occupy a fixed 48×48 region inside the existing minimum 72-point tile; three normal columns and two accessibility columns remain. Matched cards retain their lime backing, checkmark and explicit label. Dark revealed faces use the theme's light outline; matched lime faces retain a dark outline. Increased contrast strengthens the face strokes. The existing immediate answer-concealment transaction prevents old answers from animating through reset or mismatch concealment.

Chess retains cross-versus-crown silhouettes, White fill/dark outline and Black fill/light outline. Decorative geometry uses the existing computed piece extent inside each fixed square. Empty squares reserve the same region. Coordinates, side/piece/square accessibility labels, selected and accepted-destination cues, and all 44-point coordinate alternatives remain. Side is encoded by contrasting fill, not a new hue alone. Increased contrast strengthens the outlines. Existing accepted-destination motion and Reduce Motion gates remain unchanged; no motion task or rule owner is added.

Source formatting, documentation links, independent review and exact-head CI are separate requirements. Focused running-app checks must inspect ordinary/dark/increased-contrast presentation, small/largest text, pair concealment/reveal/match/reset, both Chess sides, accepted moves and retained geometry before delivery. Source inspection and the private Figma screenshot do not establish native rendering or physical-device accessibility. Record actual simulator evidence in the issue/PR; physical-iPhone and iOS 17 checks remain unavailable until performed.
