# Chess puzzle contract and validation

Issue #7's initial set uses two original king-and-queen checkmate-in-one positions, one for each moving color. There are no pawns, promotion, castling, en passant, full opponents, generated positions, scoring, or multistep tactics. Rules, validated fixtures, controller, and view are wired into two separate stable feed cards. Both colors have actual simulator gameplay evidence; current exact-head CI and fresh independent review are required before delivery.

`Sidequest/Resources/chess-puzzles.json` is the canonical fixture source. Each record contains a stable `id`, FEN, `sideToMove` (`white` or `black`), `objective` (`checkmate-in-one`), every legal UCI move, and every accepted mate. UCI moves are four lowercase coordinate characters, for example `g6g7`. Promotion suffixes are explicitly excluded. Board orientation is consistent: a1 is bottom left and h8 is top right for both colors.

`ChessPuzzleLoader` validates structural requirements and loads original bundled fixtures. `bundled(in:)` is `@concurrent` and async: file I/O and decoding leave the caller’s actor, check cancellation, and return immutable Sendable puzzles. In-memory `decode(_:)` remains synchronous. `ChessPuzzle` exposes immutable board and move sets; it is not a general chess legality engine. `ChessAttempt.tap(square)` selects only the moving side, supports reselection/deselection, and evaluates a destination against the verified sets. Wrong legal moves and illegal moves give distinct feedback and preserve the starting board. A correct move updates the derived board, records the solution, and ignores later input. A new attempt clears selection and feedback.

## Reproduce fixture validation

The independent development-only [python-chess tool](https://python-chess.readthedocs.io/en/latest/) (`chess` package 1.11.2) validates legal positions and enumerates all legal moves and checkmates. Its [GPL-3.0-or-later license](https://github.com/niklasf/python-chess/blob/v1.11.2/LICENSE.txt) applies to the tool; the app bundles no tool code or dependency. Fixture data is original, rather than imported puzzles or licensed artwork. Package version and official PyPI source archive hash are pinned in `scripts/chess-validation-requirements.txt`.

Use a disposable environment outside Git. This downloads a free local tool, with no account or service:

```sh
python3 -m venv /private/tmp/sidequest-chess-validation-venv
/private/tmp/sidequest-chess-validation-venv/bin/python -m pip install \
  --no-deps --require-hashes -r scripts/chess-validation-requirements.txt
/private/tmp/sidequest-chess-validation-venv/bin/python scripts/validate-chess-fixtures.py
```

The validator rejects invalid/already-finished positions, unsupported pieces/special moves, moving-side mismatches, duplicate IDs/moves, and any mismatch between the recorded legal/accepted sets and exhaustive engine results. It never changes fixtures or contacts a puzzle service. After fixture changes, rerun it and retain the actual output before review; unit tests alone do not establish chess legality.

Actual October 3, 2026 validation: both positions are valid and have 26 legal moves. White's complete accepted set is `g6g7`, `g6g8`, `g6h5`, `g6h6`; Black's is `b3a3`, `b3a4`, `b3b1`, `b3b2`. These complete sets deliberately accept equivalent solutions. Seven negative fixture mutations were rejected (missing mate, accepted nonmate, missing legal move, wrong side, adjacent kings, unsupported pawn, duplicate ID). Four real app-hosted rule tests passed for all eight solutions, all 44 legal nonmates, illegal moves, selection/coordinates/frozen completion, and malformed fixture data. Bundled fixture discovery passed through the actual app target. The controller, composition, and running-app checks below extend this pure-rule evidence.

## Presentation contract

App-owned `FeedSessionState` loads fixtures once before publishing composition, with accessible progress and visible failure. Its structured root task and loading identity reject canceled or stale completions. The synchronous `FeedComposition(chessPuzzles:)` retains the immutable cache and reuses it for both cards and same-view generic replacement; rendering does not reload or reshuffle. Integration #9 constructs full replacement candidates from that cache before committing news storage. The Debug generic constructor retains its separate test membership. App composition retains `ChessController(puzzle:runtime:)` per stable card ID and renders `ChessPuzzleView(controller:)`; it maps the canonical fixture IDs to the two production chess cards. The controller binds one weak synchronous effect handler to the supplied GameRuntime and owns no second lifecycle, timers, or tasks. Start creates a clean attempt with no move. Reset immediately clears unfinished rules, selection, feedback, and destination choices. Stop preserves the solved board. Each input checks the current attempt and runtime visibility; completed and offscreen input is ignored.

The controller exposes its read-only puzzle, attempt, destination file/rank, and input/submission availability. Board `tap(_:)` supports own-side selection and destinations. `selectFile(_:)` and `selectRank(_:)` accept 0...7 only after selection; `submitCoordinates()` evaluates the destination and clears coordinate choices. Coordinate selection alone makes no move. Explicit submission onto an own piece, including the selected origin, is illegal; board taps still support reselecting or deselecting an own piece. Typed feedback distinguishes selection, illegal moves, legal nonmates, and checkmate.

The view labels all board cells and keeps both colors White-oriented. Full-width own-piece buttons and native destination menus provide 44-point alternatives to small board cells; a separate Submit move button confirms the move. Each alternative sizes its label and defines a rectangular content shape so the usable region includes its padding. All game controls are inside the feed's scrollable card for Dynamic Type. Completion shows the moved queen on its destination and an empty origin, and hides further move controls.
