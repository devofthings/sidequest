# Build the iPhone MVP natively with SwiftUI

The user chose native SwiftUI over a web-first or cross-platform prototype. The first test prioritizes the reading, playing, and swiping experience on iPhone, so native presentation is worth the platform-specific investment. Other platforms remain outside the initial delivery target; third-party game rendering is still a separate decision if it becomes necessary.
