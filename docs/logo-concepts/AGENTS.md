# Logo concept ownership

- Keep these assets proposed until the owner selects a final identity under [issue #14](https://github.com/devofthings/sidequest/issues/14). Read [the concept comparison](README.md) before altering a proposal or producing assets. The lead's recommendation does not authorize integration.
- Preserve editable, original SVG geometry and accessible title/description metadata. Review PNGs are derived previews; SVGs own the artwork. Keep the provenance and reproduction instructions current when geometry changes.
- Use the existing local Node.js/Sharp renderer for proof images. This is a delegated implementation choice to make original SVGs reviewable without a new dependency, account, or charge. It is unrelated to native app verification.
- Keep production icon work separate until selection: actual system masking, appearance variants, asset-catalog integration, and simulator verification remain issue #14's later acceptance criteria. The [selected MVP visual baseline](../DESIGN.md) guides coherence, while the purple icon background remains proposed branding.
