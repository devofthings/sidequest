# Install and run Sidequest

## Verified foundation

`Sidequest.xcodeproj` contains the shared `Sidequest` scheme, iPhone app, app-hosted unit tests, and UI tests. The feed uses fictional sample news, playable mini Sudoku, memory pairs, and one-move chess puzzles, and a bubble shooter. Manual news imports are available in the standalone Debug preview while imported-news feed integration follows #9. Local simulator builds, tests, installation, and launch are verified; [Sudoku verification](SUDOKU.md#verification) records its passed delivery checks; [Memory verification](MEMORY.md#verification) records its passed focused checks and points to live PR gates. The owner chose simulator-first delivery in resolved [#79](https://github.com/devofthings/sidequest/issues/79); physical-iPhone signing and installation are deferred and unverified. The documented source-signing route requires your local Apple Account and signing configuration. [CI](CI.md) uses the same verified toolchain on a foreground self-hosted Mac runner. The retained [2026.10.7 development preview](https://github.com/devofthings/sidequest/releases/tag/2026.10.7) is an ARM64 simulator build, not the finished MVP. Older preview downloads were cleaned up at the user’s request; Git tags/source remain. Next publication is held until actual MVP readiness under [RELEASES.md](RELEASES.md).
